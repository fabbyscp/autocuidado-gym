# ❤️ AutoCuidado Gym

Projeto-escola desenvolvido em Python com o objetivo de transformar conhecimentos de programação, Backend, APIs, bancos de dados, testes, Cloud e Inteligência Artificial em uma aplicação prática.

O projeto está sendo construído de forma incremental, acompanhando minha evolução como desenvolvedora.

---

## 🎯 Objetivo

O AutoCuidado Gym começou como uma ideia de aplicação voltada para organização de treinos e autocuidado.

Neste momento, o foco principal é utilizar o projeto como ambiente de aprendizado e prática de tecnologias utilizadas no mercado de desenvolvimento Backend e IA.

## 📚 O que estou aprendendo com o projeto

O projeto está sendo desenvolvido seguindo uma abordagem incremental:

**Aprender → Implementar → Testar → Entender → Aplicar → Versionar**

A ideia é não apenas utilizar ferramentas, mas compreender como elas se conectam dentro de uma aplicação real.
